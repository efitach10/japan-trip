# יפן שלנו · Japan Trip PWA

אפליקציית טיול בעברית, מימין לשמאל, עם מסלול יומי, מלונות, מסמכים, כרטיסים, צילומים אמיתיים ואנימציות שלכת מקומיות.

התוכן האישי מוצפן באמצעות AES-256-GCM ומפתח הנגזר מהסיסמה ב־PBKDF2-SHA256. הסיסמה נמסרת בנפרד ואינה כלולה במאגר. הפענוח מתבצע במכשיר בלבד; אין שרת סיסמאות. אין להעלות למאגר עותק מפוענח, מסמכי מקור או את סיסמת הטיול.

## פרסום

הקבצים בתיקיית `site/` מוכנים לאחסון סטטי. ב־Settings → Pages יש לבחור **GitHub Actions** כמקור הפרסום. כל עדכון לענף `main` יפרסם את האתר דרך התהליך שב־`.github/workflows/pages.yml`.

כל הנתיבים יחסיים, כך שהאתר מתאים גם לכתובת פרויקט כדוגמת `https://OWNER.github.io/japan-trip/`.

## התקנה בטלפון

פתחו את כתובת האתר עם אינטרנט. במסך כלים המתינו לאישור השמירה ללא אינטרנט.

- Android / Chrome: כלים → התקנת יפן שלנו, כשהדפדפן מציע התקנה, או מתפריט הדפדפן.
- iPhone / Safari: שיתוף → הוספה למסך הבית.
- מחשב: כפתור ההתקנה בדפדפן תומך, או תפריט הדפדפן.

ההערות, המקומות השמורים והסימונים נשמרים בכל מכשיר בנפרד. אפשר להעבירם דרך גיבוי אישי במסך כלים. קישורים לכרטיסים חיים של ספקים ופתיחת ניווט במפות יכולים לדרוש אינטרנט. כרטיסי הכתובות ביפנית שמורים בתוך האפליקציה; עצירות בלי כתובת מדויקת מסומנות כאזור / מיקום לחיפוש.

## מבנה

- `site/index.html` — הממשק והמידע הכלול באפליקציה.
- `site/manifest.webmanifest` — שם, אייקונים והגדרות התקנה.
- `site/sw.js` — שמירה לשימוש ללא רשת, כולל הפעלה ממסך הבית.
- `site/icon-*.png` — אייקונים למסך הבית ול־iOS.

## בדיקה מקומית

הגישו את תיקיית `site` בשרת HTTP מקומי. כתובת localhost נחשבת הקשר מאובטח לצורך בדיקת service worker. בפרסום השתמשו ב־HTTPS.

## צילומי היעדים

הנופים הוחלפו ב־26 צילומים אמיתיים מ־Wikimedia Commons. הצילומים מוטמעים בתוך האפליקציה לשימוש ללא אינטרנט. [קרדיטים, רישיונות וקישורי הורדה לצילומים](site/photo-credits.html). הרישיונות של כל צילום חלים על הצילום עצמו; התמונה הוקטנה ונדחסה והתצוגה בכרטיס נחתכת בהתאם למסך. נוספו גם צילומי המלונות והפעילויות, עם קרדיט ומקור בתוך האפליקציה. תמונות מייצגות של טיסות ורשת השכרה מסומנות כך. עותקי הצילומים ברישיון פתוח בתיקיית `site/photos/` אינם כוללים מידע אישי מהמסלול. תמונות המלונות והמפעילים מוטמעות בתוכן המוצפן.
